Color
Overview
Shui includes a set of colors meant to be used in different elements of the UI. For light and dark Themes the colors are different, and you can switch the Theme of this page to see the colors for each.
Colors are divided in 5 sections:
Base colors are used in containers, panes, access bar and main content area.
UI colors are used on text and icons and provide good contrast when used over any background. Typography colors serves as a semantic layer for typography.
Functional colors are used for indicating status (success, warning, error).
Active tints are used for indicating active states.
Support colors are used for additional highlight.

Usage
Light vs dark theme
The choice to use light or dark themes should not be arbitrary, or because of aesthetic preferences, this choice should be informed by the purpose of the application and by its context/environment of use.
A mix of both schemes on the same page is not supported, and switching between the two themes is not recommended unless there is a strong use case or significant improvement to the user experience of the application.
When to use a light theme?
A light theme should be considered when the application is being used in brighter environments and is not being used for prolonged periods of time. It is also the preferred theme when the user is primarily engaged in reading large quantities of text, for example, in wikis or help manuals.
When to use a dark theme?
A dark theme is the preferred theme when the user needs to work with an application for long durations. The dark background is less straining to a user’s eyes as compared to the light theme. Also, if the application is used in a dark environment, then the dark theme will be more usable for extended periods of usage.
Contrast is another consideration - when applications require content such as radiology images to be the key focus, then a dark theme is highly recommended, as it allows the images to stand out against the dark interface.
DICOM color calibration
DICOM monitors support calibration in accordance with the DICOM standard for precise diagnostics. Because of this specific greyscale calibration, the contrast of some colors can be high, which makes the orange colors of Shui not as intended. Therefore, by setting the dicom property to your page, the orange colors will be updated to the values below.
Please note that these colors are only meant to be used in products that are used in DICOM compliant monitors.
